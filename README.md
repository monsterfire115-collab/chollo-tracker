# Chollo Tracker

Mini web estática para guardar y filtrar chollos (ofertas y rebajas) por categoría: tecnología, móviles, montaña, gaming y más.

A small static website to save and filter deals by category: tech, phones, mountain gear, gaming and more.

## Qué hace / Features

- Añade chollos con precio, precio anterior (calcula el % de descuento), tienda, categoría y enlace.
- Busca y filtra por categoría.
- Calcula automáticamente el porcentaje de descuento.
- Todo se guarda en `localStorage`: sin servidor, sin cuentas, sin rastreo.
- Diseño responsive, modo oscuro.

## Uso / Usage

Es una web 100% estática: abre `index.html` en el navegador o sírvela con cualquier hosting estático (GitHub Pages, Netlify, etc.).

No build step needed - plain HTML, CSS and JavaScript.
